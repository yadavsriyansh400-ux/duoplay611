# 🎮 DuoPlay611

### Play Together. Compete Together. Have Fun Together.

**DuoPlay611** is a real-time multiplayer gaming platform where two players can connect, invite each other into rooms, and enjoy interactive mini-games together.

The platform combines multiplayer gameplay, player discovery, friend requests, room invitations, and email-based authentication into one experience.

---

## ✨ Features

### 🔐 Authentication & Security
- User registration and login.
- Email verification using Brevo SMTP and Nodemailer.
- JWT-based authentication.
- Protected routes for authenticated users.
- Password hashing and secure backend authentication.

### 👥 Player & Friend System
- Search for other registered players using their Player ID.
- Send and receive friend requests.
- Accept or reject incoming requests.
- View your friends from the dashboard.

### 🏠 Multiplayer Rooms
- Create multiplayer game rooms.
- Invite friends to join your rooms.
- Receive real-time room invitation notifications.
- Manage room participation.

### 🕹️ Mini-Games

**Tic-Tac-Toe**
- Play against another player in a multiplayer room.

**Truth or Dare**
- Randomly assigns a player to give a Truth or Dare.
- Choose between Truth and Dare.
- Dare categories include Fun, Couple, and Spicy.
- Reroll prompts within the selected category.
- Complete a turn and switch players.

More mini-games are planned for future updates!
